# Day 26–27: TP vs PP vs ZeRO

Teen cuts, teen traffic patterns.

| | Kya cut hai | Kab baat hoti hai | Link |
|---|---|---|---|
| **DP / DDP** | Data | Ek baar per step, poora gradient | Bada message, kam frequency. InfiniBand chal sakta hai. |
| **ZeRO-3 / FSDP** | State `1/N` | Har step AllGather weights + ReduceScatter grads | DP jaisa volume, thodi zyada frequency. |
| **PP** | Layers | Sirf stage boundary pe activations | Chhota message. Bubble alag problem hai. |
| **TP** | Ek matrix | Har layer, forward aur backward | Chhota lekin bahut baar. NVLink. Box ke andar rakho. |

Ek badi job mein yeh mix hote hain. 8 GPUs ek node: TP=8, NVLink pe. 16 nodes: nodes ke beech DP ya ZeRO, InfiniBand pe. Pipeline tab jab layers itni hon ki bubble `(p - 1) / m` chhupa sako.

**Rule:** TP box ke andar. PP bubble ke saath layers kaat ta hai. ZeRO copies kaat ta hai. DP sabse simple sync hai jab model ek GPU pe aa jaaye.
