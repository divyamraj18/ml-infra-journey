# Day 62–63: Local cluster

```text
pip install ray
ray start --head
```

Ek task aur ek actor likho. Dashboard `127.0.0.1:8265` pe dekho: node, task timeline, object store usage.

Pehla goal do checks hain.

1. Task ka ObjectRef `ray.get` se value ban jaaye.
2. Actor ki method do baar bulao. Doosri call pehli ki state dikhaye.

**Rule:** task stateless aur retry-friendly hai. Actor state hai. Bada data ObjectRef hai, value nahi.
